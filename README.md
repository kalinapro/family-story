# Семейная история

Локальное веб-приложение для просмотра и упорядочивания семейных фотографий. Файлы обрабатываются только в браузере и **не загружаются на сервер**.

## Возможности

- множественный выбор и drag-and-drop фотографий JPG, JPEG, PNG и WEBP;
- адаптивная сетка крупных миниатюр;
- отображение имени, размера и даты съёмки;
- чтение `DateTimeOriginal` и резервного `CreateDate` из EXIF с помощью `exifr`;
- статистика фотографий с датой и без даты;
- хронологическая сортировка (фотографии без даты остаются в конце);
- удаление одной фотографии или очистка всей коллекции;
- переключение между общей коллекцией и вертикальной «Хронологией»;
- автоматическое создание событий с обложкой, диапазоном дат и превью;
- просмотр отдельного события, переименование, объединение соседних событий и разделение с выбранной фотографии;
- отдельная коллекция фотографий без даты и статистика хронологии;
- полностью локальная работа без backend, базы данных и авторизации.

## Как создаются события

Алгоритм не использует AI и вынесен в отдельную чистую функцию `groupPhotosIntoEvents` в `lib/events.ts`. Снимки с EXIF-датой сначала сортируются от старых к новым. Если между соседними снимками прошло не более шести часов, они попадают в одно событие — в том числе при переходе через полночь. Интервал больше шести часов начинает новое событие. Фотографии без EXIF-даты не группируются и показываются в отдельном блоке.

Ручные названия и изменения событий хранятся в памяти вкладки до обновления страницы. Новая загрузка пересчитывает автоматическую хронологию по всей текущей коллекции.

## Запуск

Требуется Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Проверка production-сборки

```bash
npm run lint
npm test
npm run build
npm start
```
